## What I nearly got wrong, and the instrument that caused it

**I checked those four pull requests with `get_status` and read "only the Vercel
status" — E11's exact signature for a lost CI trigger.** I was one step from
recording four green pull requests as never having run CI.

`get_status` returns only **legacy commit statuses**, and the only thing posting
one in this repository is Vercel. So it reads `total_count: 1, Vercel` on *every*
pull request here regardless of Actions. `get_check_runs` is what returns Actions
results, and by that measure all four are green on all six.

This is worse than a private slip, because **E11's own operational rule says
"count the Actions checks, and if they are absent push something real."** An
agent counting them with `get_status` would diagnose a lost trigger on every
pull request and push pointless commits to recover from nothing. Recorded as
E11's fourth sub-point, naming the call to use.
