## What was decided

- **The surcharge is derived from date of birth, never selectable.** Every field
  of `ExtrasSelection` arrives from the browser, so a surcharge placed there
  could be set to zero by a crafted request. A test reads the interface and
  fails if the key ever appears in it.
- **Browser, server and admin modal in the same commit.** The first two price
  independently and a mismatch emails the office a manipulation warning; a
  server-only change would have raised a fraud alarm on every under-23 booking.
- **No date of birth means no surcharge.** Charging a fee that cannot be
  justified from a stated fact is worse than missing one.
- **Published wording names the ages, not the euro figure**, because the figure
  is operator-editable and a number in the terms page would go stale silently.
- **`docs/OPEN-ITEMS.md` is one file with owners on every row**, rather than
  per-agent lists — an item that belongs to nobody is how things sit untouched.
