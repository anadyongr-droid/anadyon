## What was decided

- **The surcharge is derived from date of birth, never selectable.** Every field
  of `ExtrasSelection` arrives from the browser, so a surcharge placed there
  could be set to zero by a crafted request. A test reads the interface and
  fails if the key ever appears in it.
- **Browser, server and admin modal in the same commit.** The first two price
  independently and a mismatch emails the office a manipulation warning; a
  server-only change would have raised a fraud alarm on every under-23 booking.
- **No date of birth means no surcharge.** Charging a fee that cannot be
  justified from a stated fact is worse than missing one.
- **Published wording names the ages, not the euro figure**, because the figure
  is operator-editable and a number in the terms page would go stale silently.
- **`docs/OPEN-ITEMS.md` is one file with owners on every row**, rather than
  per-agent lists — an item that belongs to nobody is how things sit untouched.

- **B2 attempted and blocked.** `www.euroins.gr` and `www.intersalonica.gr` both
  return 403 at this session's egress proxy, to `curl` and the fetch tool alike.
  Not worked around, per the proxy rule. The attempt did identify the likely
  Intersalonica document and its exact URL, so it is one click for anyone
  unblocked.
- **Researched the statutory floor instead**, which both certificates incorporate
  by explicit reference — new §2b. Article 6β of PD 237/1986 excludes three
  things from compulsory cover: no licence for the category, alcohol or drugs
  contrary to ΚΟΚ art. 42, and a vehicle acquired by crime. **ΑΠ 1893/2024 holds
  those three exhaustive** — no further exclusion is permitted, not even via
  Civil Code art. 288.
- **Two consequences.** An insurer **cannot** impose an age exclusion on
  compulsory liability; age is not on a closed list. But exclusion 1 makes
  **licence category a condition of cover** — a renter on a 125 with only AM
  voids cover by statute. That is now build item **W7**, and it is the strongest
  argument yet for renting motorbikes to the age the licence permits.
- **One question raised for counsel, not answered here:** whether an art. 6β
  exclusion means the insurer refuses to pay, or pays the victim and recovers
  from us. The difference is a loss borne elsewhere versus a debt owed by
  Anadyon. Added to B4, labelled unverified.
